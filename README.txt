RBSLangApp

Что открыть:
1. Открой файл RBSLangApp.csproj в Visual Studio 2022.
2. Дождись восстановления пакетов NuGet.
3. Для Windows выбери Windows Machine, для Android — эмулятор Android.
4. Запусти проект.

Тестовые пользователи:
anna / 12345
ilya / 12345

Что есть в приложении:
- вход по логину и паролю;
- карточки уроков;
- словарь с озвучкой английских слов;
- избранные слова;
- тест по каждому уроку;
- профиль с историей результатов и выходом.

Если Visual Studio спросит про NuGet:
dotnet restore
